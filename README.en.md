## ✨ Features

- **Dual Timing Modes** - Seamlessly switch between Pomodoro timer and stopwatch
- **Immersive Experience** - Three beautiful themes (Light/Dark/Rain) with ambient sounds
- **Zen Mode** - Hide sidebars for distraction-free focus
- **Smart History** - Automatically track and save your focus sessions
- **Multi-language** - Supports Chinese, English, and Japanese
- **Zero Configuration** - Single-file deployment, works instantly

## 🎯 Advantages

- **Native Stack** - Pure HTML/CSS/JavaScript, no framework dependencies
- **Lightweight** - No build steps, blazing fast loading
- **Privacy First** - localStorage storage, your data stays local
- **Responsive Design** - Perfect on desktop and mobile
- **Progressive Enhancement** - PWA-ready, can be installed as an app

## 🚀 Quick Start

ES Modules require HTTP serving:

```bash
pnpm dlx serve
```

Or use any static server to open `index.html`.
